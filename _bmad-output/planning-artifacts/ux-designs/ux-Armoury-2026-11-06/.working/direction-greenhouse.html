Armoury UX exploration · Direction 01
Theme

Greenhouse

Security work happens in a quiet, ordered room. Calm comes from emptiness and order: one black spine for wayfinding, a paper-white list that puts “Needs attention” first and files the rest by severity, and a white detail canvas with very few numbers. Lime marks where you are and the one thing to do next; deep forest green shows what you’re looking at and draws every chart. The Light / Dark switch above shows every screen in the dark theme: same roles, same layout.

How it differs from the s.host reference

  • Keeps the shell almost as is. Same black sidebar, lime active bar, three columns, forest-green selection and tabs, small uppercase buttons.
  • The middle column sorts by need, not by kind. “Needs attention 3”, then the rest by severity (Critical, High, Medium, Low), replaces “Active / Shutdown”, so Tom’s answer is in the first heading.
  • No red alert badge. The notification count is lime on black. Severity is a word plus a small level marker in muted clay, amber, slate or green; “actively exploited” is a clay pill with an icon. Never filled red.

Rules. Lime is used only for where you are and the next action, never for text on white. Forest marks selection and draws charts. Severity is always a word plus a 4-step level marker: Critical clay, High amber, Medium slate, Low green. “Actively exploited” is a yes/no clay pill with a pulse icon. Review status (Not reviewed yet, Not impacted, Fix planned, Mitigated, Risk accepted) is a neutral grey chip with its own icon, never a severity colour. No red fills, no likelihood rating, and every text pair passes WCAG AA (4.5:1 or better). Type is the system sans, with the mono stack used only for IDs and fingerprints.
